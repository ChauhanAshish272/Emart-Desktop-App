# 🛒 Emart Desktop Application

**Emart** is a desktop-based e-commerce management system built using **Java 11**, **Java Swing**, **JDBC**, and **Oracle Database**. The application allows admins to manage products, customers, and sales while generating barcodes and invoices within a user-friendly desktop interface.

---

## 🚀 Features

- ✅ Login & authentication system
- ✅ Admin dashboard to manage inventory
- ✅ Add/update/delete products with pricing and stock
- ✅ Barcode generation for products
- ✅ Real-time order and billing system
- ✅ Invoice generation and printing
- ✅ Oracle database integration via JDBC

---
